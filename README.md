# Дипломная работа: Отказоустойчивая инфраструктура

## Описание
Разработка отказоустойчивой инфраструктуры для сайта с мониторингом, сбором логов и резервным копированием в Yandex Cloud.

## Стек технологий
- **Terraform** — развертывание инфраструктуры
- **Ansible** — конфигурация серверов
- **Yandex Cloud** — облачная платформа
- **Nginx** — веб-сервер
- **Zabbix** — мониторинг
- **Elasticsearch + Kibana + Filebeat** — сбор и визуализация логов
- **Docker** — контейнеризация Elastic-стека

## Структура проекта

├── terraform/ # IaC для развертывания инфраструктуры
├── ansible/ # Конфигурация серверов
├── docs/ # Документация и скриншоты
└── README.md
